How StegoNinja works

Steganography hides a file inside ordinary media so its very existence is concealed.

The workflow

  1. Embed — upload a cover file and the secret you want to hide; you get back a stego file.
  2. Download — save the stego file (it looks and plays like normal media).
  3. Extract — later, upload that stego file to recover the original secret.

The guided round-trip walks you through all three and keeps your settings aligned automatically.

Options

Encrypt
Vigenère-encrypts the hidden payload with your password before embedding.
Randomize
Scatters the payload across the carrier using a password-seeded sequence, so it isn't in a predictable order.
Password
Key material for encryption and randomization. It's held only in this browser tab and is never recoverable — keep it safe.

Rules that matter

  • Extraction must match embedding. Use the same technique, encryption, randomization, and password. A mismatch produces corrupt output rather than a clear error.
  • Keep stego files lossless. Outputs are BMP, WAV, or FFV1/AVI on purpose. Never re-compress or convert a stego file before extracting — hidden data does not survive lossy codecs. For video, re-upload the exact AVI you downloaded.
  • Size limit. The combined cover and secret upload must stay under 256 MB.

Privacy

StegoNinja has no accounts and stores nothing about you. Files and passwords live only in the current browser tab for the duration of an operation; each embed or extract is independent.
